# 02 - LOCAL REQUIREMENTS

## Requisitos locales

- Git instalado.
- Node.js instalado.
- VS Code o editor equivalente.
- Claude Code instalado.
- Supabase CLI instalado.
- Vercel CLI instalado.
- Login hecho en Supabase CLI.
- Login hecho en Vercel CLI.

## Comandos de comprobación

```bash
node -v
git --version
supabase --version
vercel --version
```

## Login

```bash
supabase login
vercel login
```

## Cuentas necesarias

- Supabase.
- Vercel.
- OpenRouter.
- YCloud.
- Meta Business Suite.
- HighLevel si se usará agenda/CRM.

## Consejo operativo

Si hay varias cuentas de Vercel, indicar a Claude Code desde el principio cuál debe usar.

Ejemplo:

```text
Usa la cuenta de Vercel asociada a este email: PENDIENTE DE CONFIRMAR
```
