# 09 - FIRST CLIENT STRUCTURE

## Objetivo

Crear el primer workspace piloto con documentación externa.

## Carpeta recomendada

```text
onyxlink/clientes/nombre-cliente/whatsapp-agent-workspace/
```

## Crear desde plantilla

Duplicar:

```text
onyxlink/plantillas/whatsapp-workspace-agent/
```

Dentro de:

```text
onyxlink/clientes/nombre-cliente/whatsapp-agent-workspace/
```

## Documentos mínimos antes de configurar

- CLIENT_BRIEF.md
- BUSINESS_INFO.md
- AGENT_MODE.md
- PROMPT.md
- KNOWLEDGE_BASE.md
- TOOLS_CONFIG.md
- YCLOUD_CONFIG.md
- TEST_CASES.md
- GO_LIVE_CHECKLIST.md

## Regla

La plataforma se configura desde la documentación del workspace. No improvisar dentro de la UI.
